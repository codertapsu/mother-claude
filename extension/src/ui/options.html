Mother Claude listens on 127.0.0.1, port 6725 unless you changed MOTHER_CLAUDE_PORT. The extension only ever connects to this computer.

Permissions

A fresh install does nothing in your pages. Each permission below is used only after you press its button, and you can take it back here at any time. Chrome asks you before it grants Navigation events or Downloads. The debugger comes with the install, because Chrome does not let an extension ask for it later (Chrome lists it among the extension's permissions); Grant and Remove here decide whether the extension uses it.

Sites

Sessions can read or act only on sites you let the extension into, and only as far as the site's mode in Mother Claude allows (off, read or act).

    How it behaves

    • Each Claude Code session that uses the browser gets its own colored tab group, named after the session. It works only in the tabs of its group, plus a tab you add to the group or share from the side panel.
    • Stop in the side panel ends a session's current browser command at once and refuses its next ones for a minute, unless you press Resume. Closing the group does the same.
    • Each site is off, read or act, set in Mother Claude (and from the side panel). Unknown sites are off. Sensitive sites such as banks are raised to act only on the desktop.
    • Password fields and fields that look like secrets are never read and never typed into unless you allowed it in Mother Claude for that site. Mark anything else private with a data-mc-redact attribute.
    • Risky actions wait for your answer: in the side panel, in Mother Claude, or on your phone.
    • Everything stays on this computer: the extension talks only to the Mother Claude app.
