Foreign-session control

Sessions you start in a terminal, VS Code or JetBrains are foreign: by default you can watch them here but not answer them. The Mother Claude hooks plugin lets you approve permissions, answer questions, send messages (delivered at the next tool call or when the session goes idle) and interrupt at the next tool call — from this computer or your phone. The desk UI keeps working; whoever answers first wins.

Installed as a user-scope Claude Code plugin with claude plugin install — your settings.json hooks are never touched. Uninstall removes it the same way. Sessions started before installing pick it up after a restart.
